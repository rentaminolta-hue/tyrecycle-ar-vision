5. Detection settings














Video-tuned starting point: Confidence 0.35, NMS IoU 0.45, counting line 62%. These settings are deliberately more conservative about weak detections and count only confirmed downward crossings.
Bounding boxes are mapped to the actual displayed video area (including letterbox margins) so the boxes stay aligned with the tyres. This build is tuned for the supplied conveyor video: tyres travel downward toward the camera. It uses a perspective corridor, downward-only track matching, box smoothing, short dropout recovery, three-frame confirmation, and a lower counting line. The detector remains the supplied best-3.onnx model. The loader also reads the model's actual input/output metadata rather than assuming the names.






Privacy: the selected model and camera/video are processed in the browser. The page does not upload your camera frames or model file to this app. ONNX Runtime Web is loaded from its public CDN.
